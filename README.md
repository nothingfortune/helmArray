# helmArray

One place for every control scheme you play with: two Azeron Cyborg II keypads, keyboard and
mouse, an Xbox controller and rudder pedals. Pick a game, pick a default, play. Change a
button, press Apply, and the units and the game's own binding file agree with you.

Being rebuilt from scratch. The plan, in order:

1. [Features](docs/plans/01-features.md)
2. [Architecture](docs/plans/02-architecture.md)
3. [UI system](docs/plans/03-ui-system.md)
4. [Roadmap](docs/plans/04-roadmap.md)

The first version, a YAML-and-CLI toolchain with a browser editor, is
[relayMatrix-legacy](https://github.com/nothingfortune/relayMatrix-legacy). The hardware
facts it established are in [reference/](reference/README.md).
